시사점

7/22일 이후 현재까지 측정한 2ms 동안의 6A 이상 관측된 전류는 모두 측정오차였음. 즉 계측오류임.

  • 클팸프안에 전선이 전혀 없음에도 동일한 시간폭(2ms)의 전류가 찍힘.
  • 전류프로브 degauss 해도, Auto-zero 캘리브레이션을 해도 마찬가지임.

8/14일 오후12시부터 ‘전원순단시간폭 100ms ~ 150ms’ 일 때 Latch off 발생. 인과성 바인딩 됨에 따라 → 제어전원순단시험 시퀀스 변경 후 시험실시 → 4시간 동안 9회 Latch off 발생.

  • 제어전원 Off 되어도 24V 전원은 150ms 가량 전압을 유지하다가, 전압강하시점dp 제어전원이 투입되면 Latch-off 됨. 일관된 인과성을 보임.

  • 8/14일 오후2시, 전원순단시간 100ms ~ 200ms 사이에서 Latch-off 발생환경 특정결론 후,
  • 시험환경개발 기사님 PLC 로직 수정 (릴레이 시퀀스 로직 제거, 전원만 단순히 100ms~200ms 사이 랜덤 Off)

패턴 분석

  • Latch off 발생조건 특정 : 전원차단후 24V 하강 시점에 전원재투입하면 발생빈도 증가
  • DC전원이던 AC전원이던 발생현상 동일.
  • 순단시간 1초~2초설정 시료 23대, 만 6일 운전 중. 이상무.
  • NCP1380 OCP / OVP 출력 프로빙해보니 Latch Off 소지 충분. 하지만 선종국M 의견은 이 파형은 신뢰불가. 프로브간섭 효과.
  • SMPS 에 저항부하 달고 단독으로 시험해도 동일파형 보임. 하지만 Latch Off 는 안됨. 계속 걸어두면 언젠가는 나올 듯.
  • AC 소스 재투입시 peak 에 보이는 채터링 è 급과도파형에 영향을 줌. AC소스에 담긴 채터링크기만큼 24V에 실림. 연구팀 전원소스보다 시험반측 소스가 더 심함.
  • DV 초기버전 (벌크캡 100uF 두개) 로 한 시간 남짓 시험해 보았으나 급과도파형 보이지 않음

Latch-Off 발생 메카니즘

  1. 24V 하강시점 == 벌크캡 완전방전시점.
    • 이때 AC 110V 위상각 90도 나 270도 인가시 최대 inrush 발생 → NCP1380 의 OCP 센싱부나 OVP 센싱부 EMP영향 → Latch Off
    • DC110V 인가시에도 latch off 발생동일
  1. 순단 후 재 투입시, 24V Main 에 전원소스 노이즈 유입→ Latch Off

시험반 전원소스 재투입파형 채터링

관찰 특이점

  • AC 재인가시 여러개의 Peak 에 걸쳐서 분산되는 경우, Latch Off 확률 감소
  • 전원 재인가시 첫번째 Peak 만 왜곡/채터링이 심해질 경우 Latch Off 확률 상승
  • DV 초기 SMPS 는 이 현상 발생 않음. (벌크캡 100uF, 2EA) (DV 중반 이후부터는 220uF 으로 증량)
